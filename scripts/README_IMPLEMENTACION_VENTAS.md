# Scripts de generación de clientes y ventas

- `generar_clientes.py` se conserva sin cambios.
- `generar_ventas.py` contiene el nuevo algoritmo de ventas por calendario, recompras ponderadas, tienda por región, productos estrella, asociaciones y promociones vigentes.

Copia estos archivos dentro de tu carpeta `scripts/` y ejecuta:

```bash
python scripts/generar_ventas.py
```

El script espera encontrar los CSV de dimensiones en la estructura usada por el proyecto.
